## Sobre

API REST em C# e .NET para demonstrar organizacao backend, endpoints, autenticacao e documentacao com Swagger.

O objetivo deste repositorio e demonstrar uma implementacao clara, organizada e facil de avaliar, com documentacao objetiva para recrutadores e pessoas tecnicas entenderem rapidamente o contexto do projeto.

## Funcionalidades

- API REST.
- Endpoints documentados.
- Persistencia com Entity Framework.
- Autenticacao/autorizacao.
- Execucao local com Docker.

## Stack

- **C#**
- **.NET**
- **ASP.NET Core**
- **Entity Framework**
- **Swagger**
- **Docker**

## Como executar

```bash
dotnet run
```
